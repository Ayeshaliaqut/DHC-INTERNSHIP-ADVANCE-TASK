# Data Science Internship Project Portfolio

Welcome to my internship project repository! This collection contains **7 practical data science tasks** designed to strengthen my skills in data preprocessing, EDA, classification, regression, clustering, dashboarding, time-series forecasting, and model interpretability. Each task builds real-world experience through Python, machine learning, and modern data tools.

---
## ✅ Task 1: Customer Segmentation (Unsupervised Learning)

**Objective:**  
Cluster mall customers based on spending habits to guide marketing strategy.

**Key Highlights:**
- K-Means clustering
- Dimensionality reduction via PCA & t-SNE
- Visual cluster interpretation
- Strategy recommendations per cluster

---

## ✅ Task 2: Energy Consumption Forecasting (Time Series)

**Objective:**  
Forecast short-term energy consumption from historical household data.

**Key Highlights:**
- Time parsing, resampling, and feature engineering
- Models: ARIMA and XGBoost
- Performance: MAE, RMSE comparison
- Visualization of actual vs predicted usage

---

## ✅ Task 3: Interactive Business Dashboard (Streamlit)

**Objective:**  
Develop a responsive dashboard to analyze sales, profit, and performance across product segments.

**Key Highlights:**
- Filters: Region, Category, Sub-Category
- KPIs: Total Sales, Profit, Top 5 Customers by Sales
- Built using `Streamlit` and `Plotly`
- User-friendly layout with interactive controls

**Skills Gained:**
- Business Intelligence (BI) dashboarding  
- Data storytelling  
- User interactivity with Streamlit  
- Visual KPI analysis

---

## 🛠 Tools & Libraries Used

- Python (pandas, numpy, seaborn, matplotlib, plotly)
- Scikit-learn, XGBoost, ARIMA, SHAP
- Streamlit for interactive dashboards
- PCA, t-SNE for clustering visualization
